# Ficha de Uso - DFD para o PCA

Arquivo da minuta-mae: `05_minutas/DFD/DFD_PARA_PCA_MINUTA_MAE.docx` (DOCX convertido do modelo enviado pelo usuario: `1 - DFD para o PCA.doc`).

## 1. Finalidade

Esta minuta deve ser usada para levantar, formalizar e autorizar demandas que serao incluidas no Plano de Contratacoes Anual - PCA da Camara Municipal de Itanhandu.

Ela e propria para a etapa macro de planejamento anual, antes da abertura do processo de contratacao especifico. Serve tanto para nova contratacao quanto para renovacao/prorrogacao que precise constar do PCA.

## 2. Quando usar

Use esta minuta quando o usuario pedir:

- DFD para montar o PCA;
- formulario de demanda para o Plano de Contratacoes Anual;
- inclusao de demanda no PCA;
- levantamento anual de necessidades;
- registro de renovacao contratual no PCA.

Para instruir uma contratacao concreta ja em fase preparatoria, verificar se a minuta geral `05_minutas/DFD/DFD_MINUTA_MAE.docx` e mais adequada ao caso.

## 3. Regra principal

O Charles deve preservar a estrutura oficial do modelo, preenchendo apenas os campos variaveis e selecionando os blocos aplicaveis.

O modelo contem alternativas para:

- nova contratacao; ou
- renovacao de contrato.

Nao usar simultaneamente os dois blocos quando apenas um deles for aplicavel.

## 4. Campos variaveis

| Campo | Conteudo esperado |
|---|---|
| Requisitante | Unidade ou setor que apresenta a demanda |
| Responsavel pela demanda | Nome do servidor ou responsavel tecnico/administrativo |
| Matricula | Matricula funcional, quando houver |
| E-mail institucional | E-mail oficial do responsavel |
| Telefone | Preferir telefone institucional; evitar telefone pessoal em documento publico |
| Objeto | Descricao resumida da necessidade/objeto |
| Quantidade | Quantidade estimada para o exercicio |
| Unidade de medida | Unidade aplicavel ao objeto |
| Contrato no. | Preencher apenas em caso de renovacao |
| Contratada | Preencher apenas em caso de renovacao |
| Justificativa | Necessidade administrativa e importancia da contratacao |
| Estimativa preliminar do valor | Valor estimado por procedimento simplificado, sem substituir a pesquisa de precos |
| Valor total e atualizado do contrato | Para renovacao |
| Valor atualizado a ser despendido no proximo exercicio | Para renovacao |
| Data pretendida para conclusao | Prazo desejado para formalizacao da contratacao |
| Vigencia contratual | Periodo do contrato atual e da renovacao pretendida |
| Vinculacao ou dependencia | Informar se ha dependencia com outra contratacao |
| Prioridade | Alta, media ou baixa |
| Ano do PCA | Exercicio do Plano de Contratacoes Anual |
| Numero de registro no PCA | Numero atribuido apos inclusao da demanda |

## 5. Fluxo de uso

1. A area requisitante preenche a identificacao da demanda.
2. O responsavel descreve objeto, quantidade, unidade e justificativa.
3. Em renovacao, preenche os dados do contrato vigente.
4. Informa a estimativa preliminar ou valores atualizados do contrato.
5. Indica data pretendida, vigencia, dependencia com outra contratacao e prioridade.
6. A chefia/diretoria submete a demanda.
7. A Presidencia autoriza a inclusao no PCA.
8. O servidor responsavel registra o numero da demanda no PCA.

## 6. Riscos e cautelas

- A estimativa preliminar do DFD para PCA nao substitui a pesquisa de precos exigida na fase propria do processo.
- O DFD para PCA nao substitui ETP, TR ou justificativa de contratacao direta quando esses documentos forem exigidos.
- Em caso de renovacao, conferir se a despesa prevista para o proximo exercicio esta alinhada ao planejamento orcamentario.
- Se a demanda prevista no PCA nao for executada no ano-base, reavaliar, justificar a nao execucao e reinserir no PCA do exercicio seguinte se ainda for necessaria.
- Evitar descricao excessivamente generica do objeto, pois isso prejudica a consolidacao do PCA e o controle de fracionamento.
